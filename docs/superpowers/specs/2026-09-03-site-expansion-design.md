# Site Expansion Design — Enchants, Sectioned Classes, Get Started, Top-3 Combos

Date: 2026-09-03
Status: Approved

## Goal

Extend the static ValhallaRaces compendium website (`site/`) with four additions,
all matching the existing **war-chronicle codex** design language (ink slate panels,
brass rules, Marcellus/Spectral/IBM Plex Mono type, buff-green / debuff-red):

1. An **Enchantments** page listing all ExcellentEnchants.
2. **Sectioning** the Classes page by group.
3. A **Get Started** page with a YouTube video + written how-to.
4. A **Top-3 Combos** page with an auto-scored bar graph.

## Data model

### Enchantments (`enchantments.json`)
Static, generated by `scripts/build_enchantments.py` from a hand-maintained
`scripts/enchantments.yml` (compiled from the ExcellentEnchants wiki list). JSON shape:

```json
{
  "generated": "Auto-generated by scripts/build_enchantments.py — do not edit.",
  "enchantments": [
    {
      "key": "cold_steel",
      "name": "Cold Steel",
      "category": "Armor",
      "summary": "Applies Mining Fatigue to the attacker.",
      "max_level": "III",
      "incompatible": ["Frost Walker"],
      "primary": ["Chestplate"],
      "secondary": ["Elytra"],
      "weight": 5
    }
  ]
}
```

Categories: Armor, Bow, Tool, Fishing, Weapon, Universal (6 total, ~85 enchantments).

### Combos (`combos.json`)
Static, generated by `scripts/build_combos.py`. A combo = **1 race + 3 classes**
(matching `classes-count: 3`). Score = sum of all buff magnitudes − sum of all debuff
magnitudes across the 4 entries (using the same `stats` normalization as the existing
build: magnitude in percent- or flat-units, absolute value). Top 3 kept.

```json
{
  "generated": "Auto-generated by scripts/build_combos.py — do not edit.",
  "combos": [
    {
      "rank": 1,
      "score": 123.5,
      "race": "dragonkin",
      "race_name": "Dragonkin",
      "classes": ["key1", "key2", "key3"],
      "class_names": ["Name1", "Name2", "Name3"]
    }
  ]
}
```

## Pages

### `enchantments.html`
- `data-page="enchant"`. Header nav gains an "Enchants" link; home gains a gate.
- Hero + toolbar: search input + category filter buttons (built dynamically).
- Grid of enchant cards (`.card`): name, category badge, max level, summary.
- Click opens modal (`.modal`) with summary, max level, weight, incompatible-with,
  and primary/secondary item text chips.
- Rendered via a new `enchant` path in `app.js` (`bootEnchants`), reusing card/filter/modal logic.

### Classes sectioning
- In `app.js`, `renderGrid` for `page === "class"` renders **group sections**:
  a subhead per group ("Group N · Name") followed by its cards, instead of one flat grid.
- Search and group filters still apply (filtering scopes to that group). Counts preserved.

### `getting-started.html`
- `data-page="getting-started"`. Hero + a featured YouTube embed (`youtu.be/WgYivHDmW2k`).
- Written steps: run `claimrace` to receive your single race, `claimclass` for your three
  classes (one per calling), and quick-link gates to Races/Classes/Enchants.

### `combos.html`
- `data-page="combos"`. Hero + pure-CSS horizontal bar chart of the top 3 combos by score.
- Each bar names the race + its 3 classes and the total; plus a stat-line summary.
- Data from `combos.json`.

## Navigation updates
- All page headers (`index.html`, `races.html`, `classes.html`, plus new pages) get the
  new nav entries: Home · Races · Classes · Combos · Enchants · Get Started.
- Home (`index.html`) gains gates to Enchants, Combos, and Get Started alongside existing.

## Scripts
- `scripts/build_enchantments.py` — reads `scripts/enchantments.yml`, writes
  `site/assets/data/enchantments.json`.
- `scripts/build_combos.py` — reads `plugin/races.yml` + `plugin/classes.yml`, computes
  top-3 combos, writes `site/assets/data/combos.json`.

## Out of scope
- No runtime fetching; everything is static and served with the site.
- No sprite images for items — text chips only.
- No changes to the plugin/server config.
