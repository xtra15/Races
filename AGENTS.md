## What this project is

A **Minecraft plugin configuration + companion website** for a `ValhallaRaces`
server (a Paper/Spigot Minecraft plugin that gives players stat-affecting races
and classes).

- **227 races** (each a set of stat buffs/debuffs + lore)
- **127 classes** across **10 groups** (player picks 1 class per group)
- A static **website** ("war-chronicle codex" theme) that displays all of them
  with search, group filters, and a buff/debuff detail modal.

Server runs **Paper 26.1.2** on a remote Ubuntu box. Config files are edited
**locally** (this repo) and deployed to the server manually.

## Key commands

### Rebuild website data after editing plugin YAML

```bash
python scripts/build_data.py
```

Reads `plugin/races.yml` + `plugin/classes.yml`, writes `site/assets/data/data.json`.

### Run the website locally

```bash
python -m http.server 8080 --directory site
```

Then open `http://localhost:8080/races.html` and `classes.html`.
(Data loads via `fetch`, so it needs an HTTP server — `file://` won't work.)

## Editing the plugin config (plugin/*.yml)

### races.yml format (one block per race)

```yaml
races:
  race_name:
    position: 0            # GUI slot (many slots unused now — see "no GUI" note below)
    icon: DIAMOND_SWORD:-1 # vanilla item; icon_locked: BARRIER:-1
    prefix: '&8[&cName&8]'
    display_name: '&cName'
    description:
      - '&cLore line one'
      - '&cbenefit lines + '-'stat' lines match stat_buffs below'
    stat_buffs:
      MELEE_DAMAGE_DEALT: 0.15   # decimal fraction
```

`position`, `icon`, `prefix`, `display_name` must be **unique** per race.

### classes.yml format

```yaml
classes:
  class_name:
    group: 1    # player picks one class per group; groups 1-10 used
    position: 0
    icon: IRON_SWORD:-1
    display_name: '&cName'
    description: [ ... ]
    stat_buffs: { ... }
```

### Stat key rules
- Buffs/debuffs use **ValhallaMMO stat keys** (e.g. `MELEE_DAMAGE_DEALT`,
  `ARMOR_MULTIPLIER_BONUS`, `HEALTH_BONUS`, `MOVEMENT_SPEED_BONUS`,
  `COOLDOWN_REDUCTION`, ...).
- Positive value = buff, negative = debuff. Decimals are fractions (0.15 = +15%).
- A few are "flat" (e.g. `HEALTH_BONUS`, `SCALE`) — the site marks these
  non-percent.
- Full label mapping lives in `scripts/build_data.py` (`STAT_LABELS`).

### Naming rules / meta-conventions (VISUAL, not enforced by the plugin)
- Race keys should be `snake_case` and **unique** — a race and a class must NOT
  share the same key (they collide in `icons.js` / data lookups).
- Display names must be unique too (no two races both "Phantom", etc.).
- Each entry benefits from 3-6 buffs and 2-4 debuffs, roughly balanced.
- Color codes: `&0-&f` Minecraft colors.

## Website data pipeline (IMPORTANT)

1. Edit `plugin/races.yml` / `plugin/classes.yml`.
2. Run `python scripts/build_data.py`.
3. `site/assets/data/data.json` is regenerated (adds `stats`, `group_name`,
   `group_label`, descriptions). **Never hand-edit data.json.**

### Group names (map in build_data.py)
1 Warrior · 2 Specialist · 3 Adept · 4 Healer · 5 Guardian ·
6 Shadow · 7 Warlord · 8 Mystic · 9 Artisan · 10 Weaver

The classes page builds its filter buttons dynamically from these groups.

## Icons

- `site/assets/js/icons.js` has an `ICONS` object + an `_custom` array.
- Any key **in `_custom`** renders as a hand-drawn SVG.
- Any key **not in `_custom`** falls back to a **two-letter monogram** glyph
  (rendered by `app.js`), so every entry always shows a clean mark.
- To add a custom icon: add the key to `_custom` AND give it an SVG body.
  SVG format spec: `site/assets/ICON_FORMAT.md`.

## Server deployment & DiscordSRV (operational context)

- Plugin lives in the server's `plugins/ValhallaRaces/`. Requires **ValhallaMMO**
  dependency (installed).
- `pick_race: false` / `pick_class: false` → races/classes assigned by command
  (`/races set <player> <race>`) or by an external random-assignment plugin, NOT
  via the GUI (the GUI only supports ~36 slots; 227 races won't fit).
- Classes can be locked via a `permission:` key — hidden from picker, assignable
  by command.
- DiscordSRV is installed for Discord chat relay. It works now (bot connected,
  correct channel ID). Setup notes:
  - Requires **Message Content** + **Server Members** Privileged Gateway Intents.
  - Bot needs `Send Messages`/`Embed Links` perms in the linked channel.

### Security reminder

  `E:\NewServer\plugins\ValhallaRaces\testing\` folder. If that token is still
  live, it should be **revoked + regenerated** in the Discord Developer Portal.
  Do not commit tokens to version control.
